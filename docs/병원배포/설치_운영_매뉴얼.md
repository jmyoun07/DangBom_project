# DB-care 설치·운영 매뉴얼

> **대상 독자**: 병원 원무·진료 담당자 (전산 지식 불필요)
> **적용 버전**: DB-care v2.4.1
> **문서 버전**: 초안 v1.0 (2026-08)

---

## 1. 프로그램 소개

DB-care는 병원 내부용 **당뇨 합병증 예측 프로그램**입니다.
환자의 검사 수치를 입력하면 6가지 당뇨 합병증(신장질환·망막병증·심혈관·신경병증·치매·뇌혈관)의
위험도를 AI가 예측하고, 수치 개선 시나리오 시뮬레이션과 유사 사례 비교 기능을 제공합니다.

> ⚠️ **의료적 주의**: 본 프로그램의 예측 결과는 의료진의 판단을 돕는 **참고 자료**이며,
> 의사의 진단·처방을 대체하지 않습니다. 최종 판단은 반드시 의료진이 내려야 합니다.

---

## 2. 설치 전 확인사항

| 항목 | 요구사항 |
|------|----------|
| 운영체제 | Windows 10 또는 11 (64비트) |
| 디스크 여유 공간 | 2 GB 이상 권장 |
| 관리자 권한 | **불필요** (현재 사용자 계정에 설치됨) |
| 인터넷 연결 | **불필요** (설치·사용 모두 오프라인 가능) |

- 프로그램은 설치한 PC 안에서만 동작하며, **환자 데이터를 외부 인터넷으로 전송하지 않습니다.**
- 화면 표시에 필요한 구성요소(Microsoft WebView2)는 설치 파일에 포함되어 있어 자동 설치됩니다.

---

## 3. 설치 방법

1. 전달받은 설치 파일 **`DB-care_2.4.1_x64-setup.exe`** (약 440 MB)를 더블클릭합니다.
2. 설치 마법사가 한국어로 표시됩니다. **[다음]** → **[설치]** 를 순서대로 누릅니다.
3. 설치가 끝나면 바탕화면과 시작 메뉴에 **DB-care** 아이콘이 생깁니다.
4. Windows가 "알 수 없는 게시자" 경고(SmartScreen)를 표시할 수 있습니다.
   **[추가 정보] → [실행]** 을 누르면 계속 진행됩니다.

> 💡 백신 프로그램이 설치를 잠시 검사할 수 있습니다. 정상적인 동작이니 완료될 때까지 기다려 주세요.

---

## 4. 첫 실행

1. 바탕화면의 **DB-care** 아이콘을 더블클릭합니다.
2. 첫 실행 시 내부 분석 엔진이 준비되는 데 **10~30초** 정도 걸릴 수 있습니다.
3. 홈 화면(CSV 업로드)이 나타나면 정상적으로 실행된 것입니다.

---

| **시나리오 분석** | C-peptide·당화혈색소 슬라이더로 "치료 방치 vs 집중관리" 미래 비교 |

## 6. 환자 데이터 등록 (CSV 업로드)

### 6.1 준비물

함께 전달드린 양식 파일을 사용합니다.

- **`병원_데이터_양식_v2.csv`** — 입력 양식 (엑셀에서 열어 작성)
- **`병원_데이터_양식_코딩북.xlsx`** — 각 항목의 의미·단위·입력 규칙 설명서

### 6.2 필수 입력 항목

아래 항목이 없으면 해당 행은 **저장·예측되지 않습니다.**

| 필수 항목 | 비고 |
|-----------|------|
| 성별 (`sex`) | 1=남, 2=여 (코딩북 참조) |
| 공복혈당 (`HE_glu`) | mg/dL |
| 당화혈색소 (`HE_HbA1c`) | % |
| 나이 또는 생년월일 | `age` 또는 `dob` 중 하나 |

나머지 항목(키·몸무게·혈압·지질·간수치·소변검사 등)은 **측정한 원본값만** 입력하면 됩니다.
BMI, eGFR, LDL(미측정 시) 등 계산값은 프로그램이 자동으로 산출합니다.

### 6.3 업로드 절차

1. **홈** 화면에서 작성한 파일을 드래그하거나 **[파일 선택]** 으로 지정합니다.
2. 화면에 **컬럼 매핑 미리보기**와 **유효성 검사 결과**가 표시됩니다.
   - 🔴 오류(필수 컬럼 누락 등)가 있으면 파일을 수정해 다시 업로드하세요.
3. **[데이터 처리 및 프로필 생성]** 을 누르면 환자 등록과 AI 예측이 자동으로 진행됩니다.

### 6.4 알아두면 좋은 동작 방식

- 같은 환자(차트번호)의 **같은 검사일** 데이터를 다시 올리면 중복 등록되지 않고 갱신됩니다.
- 필수 검사값이 빠진 행은 예측 없이 "부분 방문"으로만 기록되며, 업로드 결과 화면에 사유가 표시됩니다.
- 여러 검사일 데이터를 한 파일에 넣어 올리면 검사 이력이 시계열로 쌓입니다.

## 7. 유사 사례(졸업자) 데이터 업데이트

유사 사례 비교에 사용되는 "졸업자(관리 성공 사례)" 데이터는 프로그램 재설치 없이 갱신할 수 있습니다.

1. **설정** 화면으로 이동합니다.
2. **졸업자 엑셀 파일**을 업로드합니다.
3. 기존 졸업자 데이터가 새 파일 내용으로 **전체 교체**됩니다.

> ⚠️ **전체 교체입니다.** 새로 추가된 분만 담은 파일을 올리면 기존 졸업자가 사라집니다.
> 항상 **전체 명단이 든 하나의 파일**을 유지하면서 갱신해 주세요.

**최초 1회**: 별도로 전달받은 `졸업자_임상데이터_업로드용.xlsx` (208명) 를 올리면 됩니다.
이 파일에는 환자 실명이 들어 있어 프로그램 설치 파일과 분리해 전달됩니다.
업로드 전까지 유사 사례 화면은 비어 있고, 다른 기능은 정상 동작합니다.

**앞으로 추가하실 때**: `졸업자_RAW_데이터셋_양식_병원발송용.xlsx` 양식에 이어서 채웁니다.
파일 안의 **'코딩북'·'작성방법'** 시트에 항목별 입력 규칙이 있습니다. 요점만 적으면,

- **1명 = 2줄** (초진 1줄 + 졸업 1줄), `visit_type` 으로 구분합니다.
- 같은 분의 두 줄은 **`chart_no` 가 완전히 같아야** 한 사람으로 묶입니다.
- 검사를 안 한 항목은 `0` 이 아니라 **빈칸**으로 둡니다. (`0` 은 측정값 0으로 처리됩니다)
- 수치는 숫자만 넣습니다. `7.2%`, `120 mmHg` 처럼 단위를 같이 쓰면 인식되지 않습니다.
- **합병증 위험도는 입력하지 않으셔도 됩니다.** 검사 수치를 넣으면 프로그램이 계산합니다.

## 8. 데이터 저장 위치와 백업

### 8.1 데이터는 어디에 저장되나요?

모든 환자 데이터는 설치한 PC의 아래 폴더에 저장됩니다. (외부 전송 없음)

```
C:\Users\<사용자명>\AppData\Roaming\DB-care\
├── dbcare.db      ← 환자 데이터베이스 (핵심 파일)
├── backend.log    ← 프로그램 동작 기록 (문제 해결용)
└── export\        ← 환자별 CSV 자동 사본 (환자별 폴더 → 정보.csv, 검사_이력.csv)
```

> 💡 `AppData` 폴더가 보이지 않으면: 파일 탐색기 주소창에 `%APPDATA%\DB-care` 를 입력하세요.

### 8.2 백업 방법 (주 1회 권장)

1. **설정 → 백업** 에서 **[백업]** 버튼을 누르면
   `dbcare_patients_backup_날짜.csv` 파일이 다운로드됩니다.
2. 이 파일을 병원 내부 보관 위치(외장하드, 내부 서버 등)에 복사해 두세요.
3. 더 확실한 백업을 원하면 `%APPDATA%\DB-care` 폴더 전체를 복사해도 됩니다.
   (`dbcare.db` 파일만 있으면 환자 데이터 전체가 복원됩니다.)

### 8.3 전체 데이터 삭제 (주의)

**설정** 화면의 전체 환자 데이터 삭제 기능은 **되돌릴 수 없습니다.**
확인창에 `DELETE` 를 직접 입력해야 실행되며, 실행 전 반드시 백업을 먼저 저장하세요.

## 9. 개인정보 보호

- 환자 데이터는 **설치된 PC 안에만** 저장되며, 프로그램이 인터넷으로 데이터를 보내지 않습니다.
  (내부 분석 엔진은 같은 PC 안(127.0.0.1)에서만 통신합니다.)
- 따라서 개인정보 보호를 위해 다음을 권장합니다.
  - 프로그램이 설치된 PC에 **Windows 로그인 암호** 설정
  - 백업 CSV 파일을 이메일·메신저로 전송하지 않기 (환자 정보 포함)
  - PC 폐기·교체 시 `%APPDATA%\DB-care` 폴더 완전 삭제

## 10. 문제 해결 (FAQ)

| 증상 | 조치 |
|------|------|
| 아이콘을 눌러도 창이 안 뜸 | PC를 재부팅한 뒤 다시 실행해 보세요. 반복되면 `%APPDATA%\DB-care\backend.log` 파일을 개발팀에 보내주세요. |
| "백엔드 연결 실패" 류의 오류 | 프로그램을 완전히 종료 후 다시 실행하세요. 다른 프로그램이 8765 포트를 사용 중이면 충돌할 수 있습니다. |
| 업로드 시 "필수 컬럼 누락" 오류 | 양식 파일의 첫 행(컬럼명)이 수정되지 않았는지, 성별·공복혈당·당화혈색소·나이(또는 생년월일)가 채워졌는지 확인하세요. |
| 화면이 하얗게만 나옴 | 프로그램 재시작 → 그래도 안 되면 재설치(11장). 환자 데이터는 재설치해도 유지됩니다. |
| 백신이 프로그램을 차단함 | 백신 설정에서 DB-care를 예외(허용) 목록에 추가하세요. |
| 예측 결과가 이상해 보임 | 입력 수치의 단위·오타를 먼저 확인하세요. 위험도 산출 방식이 궁금하면 개발팀에 문의하세요. |

## 11. 업데이트·재설치·삭제

- **업데이트**: 새 버전의 `DB-care_x.x.x_x64-setup.exe` 를 받아 실행하면 기존 버전 위에 덮어 설치됩니다.
  **환자 데이터는 그대로 유지됩니다.**
- **재설치**: Windows [설정 → 앱] 에서 DB-care 제거 후 설치 파일을 다시 실행합니다.
  제거해도 환자 데이터(`%APPDATA%\DB-care`)는 지워지지 않습니다.
- **완전 삭제** (환자 데이터까지 제거): 프로그램 제거 후 `%APPDATA%\DB-care` 폴더를 직접 삭제합니다.
