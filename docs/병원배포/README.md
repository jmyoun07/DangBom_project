# 병원 배포용 졸업자 데이터

유사사례(비슷한 환자의 개선 사례) 기능은 **졸업자 데이터**를 근거로 동작한다.
합병증 위험도는 병원이 입력하는 값이 아니라, 여기 담긴 검사수치를 ML 모델에 넣어 자동 산출한다.

## 이 폴더의 파일

| 파일 | 용도 | 저장소 포함 |
|---|---|---|
| `졸업자_RAW_데이터셋_양식_병원발송용.xlsx` | 앞으로 채워 나갈 **빈 양식 + 코딩북 + 작성방법** (예시 3행은 가상 인물) | ✅ 포함 |
| `졸업자_임상데이터_업로드용.xlsx` | 실제 졸업자 208명 데이터 — 프로그램에 바로 넣는 파일 | ❌ **미포함** |

## 실데이터 파일이 왜 없나

실명·차트번호·연락처가 들어 있어 개인정보로 분류된다. 소스코드와 같은 경로로 유통되면
관리 범위를 벗어나므로 저장소에서 제외하고 **암호화 파일로 별도 전달**한다.
`.gitignore` 에 등록돼 있어 실수로 다시 커밋되지 않는다.

받지 못했다면 담당자에게 요청한다. 업로드 전까지 유사사례 페이지는 비어 있고,
다른 기능(예측·시나리오·환자 관리)은 정상 동작한다.

## 데이터 갱신 방법

1. `졸업자_RAW_데이터셋_양식_병원발송용.xlsx` 의 **'코딩북'·'작성방법'** 시트를 먼저 읽는다.
2. **'데이터' 시트**에 졸업자를 채운다. **1명 = 2행**(초진 1행 + 졸업 1행), `visit_type` 으로 구분.
3. 프로그램 → **설정 → 졸업자 엑셀 업로드**.

> **업로드는 덮어쓰기(전체 교체)다.** 새로 추가된 사람만 담은 파일을 올리면
> 기존 졸업자가 사라진다. **항상 전체 명단이 담긴 하나의 파일**을 유지하며 갱신한다.

### 채울 때 자주 나는 실수

- **초진·졸업 두 행의 `chart_no` 가 다르면** 같은 사람으로 묶이지 않는다 — 완전히 동일해야 한다.
- 날짜는 `YYYY-MM-DD`. 엑셀이 날짜 서식으로 바꿔도 무방하나, `26/5/22` 같은 두 자리 연도는 피한다.
- 수치는 **숫자만** 넣는다. `7.2%`, `120 mmHg`, `미검사` 같은 문자는 빈칸으로 둔다.
- 빈칸은 허용된다(모델이 보정). 잘못된 값을 채워 넣는 것보다 비워 두는 편이 정확하다.
- 검사를 안 했다면 `0` 이 아니라 **빈칸**이다. `0` 은 실제 측정값 0 으로 처리된다.
