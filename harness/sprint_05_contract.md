# Sprint 5 계약: Home CSV 업로드 + CaseComparison 유사 사례 페이지

## 목표
CSV 업로드 페이지와 유사 사례 분석 결과 페이지 구현.

---

## 구현 항목

### 1. Home 페이지 — CSV 데이터 업로드
- [ ] 드래그&드롭 업로드 영역 (점선 테두리, 업로드 아이콘)
- [ ] "파일 선택" 버튼
- [ ] 선택된 파일명 표시 (파일 아이콘 + 파일명)
- [ ] "예시 CSV 템플릿 다운로드" 버튼 (핑크 outline)
- [ ] 매핑 미리보기 테이블 (CSV 컬럼 → DB 필드 → 상태)
  - 상태 컬럼: ✓ 성공(초록) / ⚠ 경고(주황) / ✗ 오류(빨강)
- [ ] 유효성 검사 피드백 패널 (우측):
  - 빨강 △: 날짜 형식 오류 / 값 범위 초과
  - 주황 △: 필수 컬럼 누락
  - 파란 ○: 전체 매핑 성공
- [ ] "데이터 처리 및 프로필 생성" 버튼 (보라, 하단 중앙)
- [ ] API: POST /api/v1/upload/csv
- [ ] CSV 업로드 성공 시 → PatientList 페이지로 이동

### 2. CaseComparison 페이지
- [ ] 페이지 제목 + 환자명 동적 삽입
- [ ] 탐색 과정 4단계 수평 스텝퍼
  - 원형 아이콘(보라) + 연결선 + STEP 번호 + 제목
  - 모든 스텝 완료 체크(✓) 상태
- [ ] "최적의 매칭 사례 총 3건" 헤더 + "유사도 순" 정렬 표시
- [ ] 매칭 사례 카드 3개 (가로 배치):
  - 이름 마스킹(김*현) + 유사도 배지(초록)
  - 나이·성별·진단 년차
  - HbA1c 변화 (X%→X%)
  - 치료기간 + "집중케어" 배지(파란)
  - 합병증 위험도 변화 6행 (이전=빨강바 / 이후=파란바)
  - 예상 의료비 절감 / 기대 건강수명
  - "상세 리포트 보기 >" 링크
- [ ] API: GET /api/v1/case-comparison/{patientId}
