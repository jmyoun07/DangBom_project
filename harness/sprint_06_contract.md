# Sprint 6 계약: 통합 테스트 + 버그 수정 + UI 폴리싱

## 목표
전체 플로우 E2E 테스트. 버그 수정. 병원 데모를 위한 완성도 향상.

---

## 구현 항목

### 1. E2E 플로우 테스트
- [ ] Home → CSV 업로드 → PatientList → PatientDetail → Dashboard → RiskAnalysis → CaseComparison 전체 흐름 실행
- [ ] 버그 발견 시 즉시 수정

### 2. 데모용 시드 데이터 보강
- [ ] 환자 10명 이상, 각 위험도 고루 분포
- [ ] 박영수(고위험) 환자 데이터 Visily UI 수치와 일치
  - HbA1c: 8.4%, 혈압: 145/90, C-peptide: 4.2 ng/mL, 기간: 8개월
- [ ] 6개월 측정 이력 데이터 실제 추이처럼 자연스럽게

### 3. 반응형 + 접근성
- [ ] 1280px, 1440px 해상도에서 레이아웃 깨지지 않음
- [ ] 로딩 스피너 모든 API 연동 부분에 표시
- [ ] 에러 상태 UI (API 실패 시 에러 메시지)

### 4. 성능
- [ ] 슬라이더 debounce 300ms 적용 확인
- [ ] 초기 페이지 로딩 3초 이내

### 5. 폴리싱
- [ ] 호버 상태 (버튼, 카드, 테이블 행)
- [ ] 트랜지션 애니메이션 (위험도 변경 시, 페이지 전환 시)
- [ ] 폰트 일관성 (한국어 시스템 폰트 또는 Noto Sans KR)
