# Sprint 4 계약: PatientList + PatientDetail 페이지

## 목표
환자 목록 관리 페이지와 환자 상세 정보 페이지 구현.
검색은 이름·차트번호·연락처 모두 가능.
최근 검사 수치는 한의원 검사 기준 14개 항목만 표시.

---

## 구현 항목

### 1. PatientList 페이지

#### 검색창
- placeholder: "이름, 차트번호 또는 연락처로 검색..."
- 입력값을 `search` 쿼리 파라미터로 전달
- 백엔드: name LIKE / chart_no LIKE / phone LIKE OR 조건 처리

#### 필터
- 합병증 위험도 드롭다운: 전체 / 저위험 / 중위험 / 고위험
- 업로드일 날짜 선택 (기간 선택)

#### 테이블
- 컬럼: 이름 / 차트번호 / 나이 / 성별 / 업로드일 / 위험도(RiskBadge) / 관리(상세보기>)
- 행 hover 시 배경색 변경
- "상세보기 >" 클릭 → /patients/{id} 이동

#### 페이지네이션
- 8명씩 표시
- 이전 / 번호 / 다음 버튼
- "전체 X명 중 1-8 표시 중" 카운트 텍스트

#### 푸터
- 이용약관 / 개인정보처리방침 / 도움말

---

### 2. PatientDetail 페이지

#### 상단 네비게이션 바
- "< 환자 목록으로 돌아가기" 링크
- "환자명 환자 상세 정보" 타이틀
- 우측: "데이터 수정" 버튼(outline) + "결과 리포트 출력" 버튼(primary)

#### 좌측 — 기본 정보 카드
- 보라색 원형 아바타
- 이름 + 차트번호 (CN-XXXX-XXXX)
- 항목: 생년월일 / 나이·성별 / 연락처 / 최근 내원일

#### 우측 상단 — AI 합병증 예측 결과
- "AI 분석 완료" 배지 (보라색)
- 완성된 알고리즘(신장질환·망막병증·신경병증)만 카드 표시:
  각 카드: 합병증명 + 위험도 배지 + "위험지수 XX/100" + 빨강 진행 바

#### 우측 중단 — 수치 추이 차트 3개 (Recharts LineChart)
- C-peptide (ng/mL) — 초록 선
- HbA1c (%) — 빨강 선
- Cr 크레아티닌 (mg/dL) — 파란 선
- 각각 6개월 월별 추이

#### 하단 — 최근 검사 수치 테이블 (2열, 한의원 검사 기준)
**정확히 아래 14개 항목을 순서 그대로, 좌열 7개 / 우열 7개로 분할:**

좌열 (1~7번):
1. 당화혈색소 (HbA1c) — %
2. C-peptide — ng/mL
3. 공복혈당 — mg/dL
4. GGT — U/L
5. ALT — U/L
6. AST — U/L
7. Cr (크레아티닌) — mg/dL

우열 (8~14번):
8. 총콜레스테롤 — mg/dL
9. 중성지방 — mg/dL
10. HDL 콜레스테롤 — mg/dL
11. LDL 콜레스테롤 — mg/dL
12. 수축기혈압 — mmHg
13. 이완기혈압 — mmHg
14. 체질량지수 (BMI) — kg/m²

**⚠️ 절대 포함하지 않을 항목:**
- 흡연여부 (검사수치 아님)
- 당뇨병 이환기간 (검사수치 아님)
- 혈중요소질소 (한의원 미시행)
- 헤모글로빈 (한의원 미시행)
- 백혈구 수 (한의원 미시행)

**비고 컬럼 판정 및 색상:**
- 정상 → 초록 텍스트
- 높음 → 빨강 텍스트
- 주의 → 주황 텍스트
- 낮음 → 파란 텍스트

비고 판정 기준:
| 항목 | 정상 | 주의 | 높음 |
|------|------|------|------|
| HbA1c | ≤5.6% | 5.7~6.4% | ≥6.5% |
| C-peptide | 0.6~3.0 ng/mL | — | 범위 밖 |
| 공복혈당 | ≤99 | 100~125 | ≥126 |
| GGT | ≤50 | — | >50 |
| ALT | ≤40 | — | >40 |
| AST | ≤40 | — | >40 |
| Cr | 0.6~1.2 | — | >1.2 |
| 총콜레스테롤 | ≤199 | 200~239 | ≥240 |
| 중성지방 | ≤149 | 150~199 | ≥200 |
| HDL | ≥60(정상) | 40~59 | <40(낮음) |
| LDL | ≤129 | 130~159 | ≥160 |
| 수축기혈압 | ≤119 | 120~139 | ≥140 |
| 이완기혈압 | ≤79 | 80~89 | ≥90 |
| BMI | ≤22.9 | 23~24.9 | ≥25 |

#### 하단 우측 — CTA 카드
- 차트 아이콘 + "합병증 위험 분석" 타이틀
- "분석 레포트 생성하기 →" 버튼 (primary)

## 검증 기준

| # | 기준 | 방법 |
|---|------|------|
| 1 | 환자 목록 8명 표시 + 페이지 이동 | 클릭 확인 |
| 2 | 이름으로 검색 필터링 동작 | 이름 입력 |
| 3 | 차트번호로 검색 필터링 동작 | 차트번호 입력 |
| 4 | **연락처로 검색 필터링 동작** | 전화번호 일부 입력 |
| 5 | 위험도 드롭다운 필터 동작 | 고위험 선택 |
| 6 | 상세보기 → PatientDetail 이동 | 클릭 확인 |
| 7 | PatientDetail 추이 차트 3개 렌더링 | 화면 확인 |
| 8 | 최근 검사 수치 **정확히 14개** 항목만 표시 | 항목 수 확인 |
| 9 | 제외 항목(흡연·이환기간·BUN·Hb·WBC) **없음** | 화면 확인 |
| 10 | 비고 컬러 판정 올바름 | 수치 범위 확인 |
| 11 | "결과 리포트 출력" 버튼 표시 | 화면 확인 |
| 12 | 뒤로가기 → 목록 복귀 | 링크 클릭 |
