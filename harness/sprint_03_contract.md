# Sprint 3 계약: RiskAnalysis — 시나리오 기반 합병증 분석 ★

## 목표
DB-care의 핵심 킬러 기능.
슬라이더 2개(C-peptide, HbA1c) → 레이더 차트 + 방치 vs 집중관리 시나리오 실시간 비교.

---

## 구현 항목

### 1. RadarChart 공통 컴포넌트
```
props: data({kidney, cardio, cerebro, dementia, retina, neuro})
- Recharts RadarChart, PolarGrid, PolarAngleAxis, Radar
- 6축 한글 레이블: 신장질환 / 심혈관 / 뇌혈관 / 치매 / 망막병증 / 신경병증
- 채우기: rgba(99, 102, 241, 0.3) (연보라)
- 테두리: #6366f1
- 슬라이더 값 변경 시 부드러운 업데이트
```

### 2. 슬라이더 패널 구현
- C-peptide 슬라이더: range 0.5~5.0, step 0.1
- HbA1c 슬라이더: range 5.0~15.0, step 0.1
- 현재값 파란색 숫자로 우측 표시
- "초기화" 버튼: 환자 원래 수치로 복귀
- Tip 박스 (회색 배경)

### 3. 시나리오 비교 패널 (2열)

왼쪽 "치료 방치 시":
- 주황 원 아이콘
- 예상 건강수명 / 예상 의료비 (큰 빨간 숫자 + 증가율)
- 지표 악화 예측 섹션
- 합병증 위험도 6행 바 차트
- 전조 증상 bullet list

오른쪽 "집중관리 시 (6개월 후)":
- 초록 번개 아이콘
- 예상 건강수명 / 예상 의료비 (큰 초록 숫자 + 감소율)
- 지표 개선 예측 섹션 (화살표 →)
- 합병증 위험도 6행 바 차트 (모두 초록)
- 기대 건강 변화 bullet list

### 4. 권장 프로그램 배너
- 보라색 배경 카드
- 프로그램명 + 설명 + "프로그램 신청 안내 ↗" 버튼

### 5. API 연동
- 슬라이더 변경 → useDebounce(300ms) → POST /api/v1/scenario/simulate
- 로딩 중: 슬라이더 비활성화 + 스피너
- 에러 시: 토스트 메시지
