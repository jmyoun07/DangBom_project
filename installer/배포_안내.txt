================================================================
 DB-care 설치 안내 (원내 PC 담당자용)
================================================================

[1] 설치 파일
  DB-care_Setup_v2.1.1.exe  (약 200~250 MB)

[2] 설치 절차
  1) USB / 메일 / 네트워크 공유로 setup 파일을 PC 로 복사
  2) setup 파일 더블클릭
  3) ★ "Windows에서 PC를 보호했습니다" 메시지가 뜨면:
       → [추가 정보] 클릭 → [실행] 클릭
       (코드 사이닝 인증서가 없는 사내 프로그램에서 흔히 발생.
        병원 IT 보안 정책상 정상이며 안전합니다.)
  4) UAC (관리자 권한 요청) 가 뜨면 [예] 클릭
       → 만약 관리자 권한이 없는 계정이면 자동으로 사용자 폴더에 설치됨
  5) "설치 완료" 화면 → DB-care 자동 실행
  6) 첫 실행은 5~60초 (느린 PC 는 최대 3분) 걸릴 수 있음.
     검은 콘솔 창이 뜨더라도 끄지 말고 기다리기.

[3] 환자 데이터 보존
  - 환자 정보 / 검사 기록은 %APPDATA%\DB-care\ 폴더에 저장됩니다.
  - 재설치 / 업데이트 시 자동으로 유지됩니다.
  - 제거 시 사용자가 "환자 DB 도 삭제하시겠습니까?" 라고 묻습니다.

[4] 설치 실패 시 점검 사항
  □ Windows 10 또는 11 (64비트) 사용 중인가?
  □ 디스크 여유 공간 1 GB 이상?
  □ 백신이 setup 파일을 격리하지 않았는가?
      → 설치 폴더와 %APPDATA%\DB-care 를 백신 예외로 추가
  □ "DB-care 백엔드 서버를 시작할 수 없습니다" 메시지박스가 떴다면
      → 메시지박스 전체를 캡처해서 IT 담당자에게 전달.
        환경 진단 정보(Windows/VC++/WebView2/Edge/RAM)가 표시됩니다.

[5] 자동 설치되는 런타임
  설치 마법사가 다음 두 가지를 자동으로 점검 후 필요 시 설치합니다.
  미리 받아둘 필요는 없지만, 인터넷이 차단된 PC 는 별도 설치 필요.

  • Microsoft Visual C++ 2015-2022 (x64) Redistributable
      https://aka.ms/vs/17/release/vc_redist.x64.exe
  • Microsoft Edge WebView2 Runtime
      https://go.microsoft.com/fwlink/p/?LinkId=2124703

[6] 흔한 증상별 해결법

  [증상 A] Edge 가 떴는데 "127.0.0.1 연결을 거부했습니다"
    원인  : 백엔드가 시작 못 함 (백신 격리 / VC++ 미설치 가능성)
    해결  : 작업 관리자에서 DB-care.exe 모두 종료 → 재실행.
            그래도 안 되면 백신 예외 추가 후 재설치.

  [증상 B] "Windows에서 PC를 보호했습니다" 만 뜨고 설치 못 함
    원인  : SmartScreen 차단 (서명 없는 exe)
    해결  : [추가 정보] → [실행] 클릭

  [증상 C] 첫 실행이 1분 넘게 검은 화면
    원인  : 느린 HDD + 백신 실시간 스캔 동시 진행
    해결  : 그대로 기다리기. 최대 3분까지 정상. 그 후엔
            "백엔드 시작 실패" 메시지가 뜸 (그 경우 IT 문의).

  [증상 D] 설치 후 바탕화면에 아이콘이 없음
    원인  : 설치 마법사에서 [바탕화면 바로가기 생성] 체크 누락
    해결  : 시작 메뉴에서 "DB-care" 검색해서 실행
            또는 재설치 시 체크박스 활성화

[7] 로그 파일 위치
  문제 발생 시 IT 담당자에게 전달하면 원인 분석 가능:
    %APPDATA%\DB-care\launcher.log
