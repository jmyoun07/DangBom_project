========================================
 DB-care — 당뇨 합병증 예측 프로그램
 병원 설치 가이드 (v1.0.0)
========================================

본 프로그램은 의사가 환자 데이터를 입력하면 AI가 6개 합병증
위험도를 예측하고 시뮬레이션을 통해 관리 시나리오를 비교하는
병원 내부용 소프트웨어입니다.


[ 시스템 요구사항 ]
-------------------
- OS      : Windows 10/11 (64-bit) 또는 macOS 12+ / Linux
- Python  : 3.11 이상 (https://www.python.org/downloads/)
- 브라우저 : Chrome, Edge, Safari 최신 버전
- 디스크  : 500MB 이상 여유 공간
- 메모리  : 4GB 이상


[ 설치 방법 ]
-------------

### Windows

1) 압축 파일을 원하는 폴더에 푼다 (예: C:\DB-care)
2) Python 3.11 이 설치되어 있는지 확인
   (명령 프롬프트에서 `python --version`)
3) 설치 폴더 안에서 `install.bat` 을 더블클릭
   → 최초 1회만 실행하면 됩니다. (약 2~3분 소요)
4) 설치가 끝나면 `start.bat` 을 더블클릭
   → 자동으로 서버가 시작되고 브라우저가 열립니다.

### macOS / Linux

1) 압축 파일을 원하는 폴더에 푼다
2) 터미널에서 해당 폴더로 이동
3) 최초 1회: `bash install.sh`
4) 실행: `bash start.sh`


[ 프로그램 사용 ]
-----------------
- 서버가 실행되면 자동으로 브라우저에서 http://localhost:8000 이 열립니다
- 환자 데이터(CSV)를 Home 메뉴에서 업로드
- Patient List 에서 환자 선택 → Dashboard / Risk Analysis / Case Comparison
- 종료하려면 검은 콘솔 창을 닫으면 됩니다


[ 문제가 생기면 ]
-----------------
- 포트 8000 이 이미 사용 중이라는 에러가 나면,
  다른 프로그램을 종료하거나 시스템을 재부팅한 뒤 다시 시도하세요.
- Python 이 설치되어 있지 않다는 에러:
  https://www.python.org/downloads/ 에서 Python 3.11 설치 (설치 시 "Add to PATH" 체크)
- 기술 지원: 담당 엔지니어에게 문의


[ 환자 데이터 보안 ]
--------------------
- 본 프로그램은 전적으로 로컬 컴퓨터에서만 실행됩니다.
- 환자 데이터는 외부 서버로 전송되지 않습니다.
- 데이터는 설치 폴더의 backend/dbcare.db 에 암호화되지 않은
  SQLite 로 저장되니, 병원 보안 정책에 따라 관리하세요.
